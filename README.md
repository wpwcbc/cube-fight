# Cube Fight

A Unity project exploring real-time rendering techniques
and graphics performance optimization using URP.

## Rendering Experiments

### Outline Rendering Benchmark

A comparative performance study of three rendering configurations:

- Baseline (without outlines)
- Inverted Hull Outline
- Depth-based Screen-space Outline

The benchmark includes implementation details, GPU profiling,
performance comparisons, and technical observations.
